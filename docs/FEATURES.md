# 功能与宿主映射

首个公开版本 0.1.0；目标宿主为思源 3.8.8 桌面端，SDK 1.2.9。所有网页都是原生 Custom 标签，未另造标签管理器。

| 功能 | 实现与边界 |
| --- | --- |
| 网页打开 | 地址、域名、关键词、笔记 HTTP(S) 外链接管、当前/新标签、右/下分屏、独立窗口、系统浏览器入口 |
| 标签 | 标题、图标和布局由思源原生标签承载；加载时在图标位置显示旋转圆环，完成、停止、失败及切换内部页时恢复图标；固定标签也支持。锁定、移动、关闭其他等沿用宿主菜单。没有模拟其他软件的关联标签机制，也未验证关联标签语义。 |
| 浏览 | 前进、后退、刷新、地址复制、书签、历史（上限 1000）、地址建议键盘选择、搜索引擎和主页设置 |
| 内置主页 | `siyuan-browser://home`；书签、最常访问、最近关闭（上限 50）、历史；条目显示网站 favicon，获取失败时保留域名首字母。区域独立开关，拖拽或上下按钮排序，配置持久化。使用思源列表、按钮、开关、图标及主题变量，窄面板单列。每个区域就地展开或收起，不再跳转独立的书签/历史标签页。 |
| 侧栏资料库 | 左侧停靠面板列出书签与历史，本地搜索、切换列表、分批加载与逐条删除；与主页共用条目组件。 |
| 阅读 | Defuddle 0.19.4 full + DOMPurify，思源排版变量；普通网页及阅读模式查找、缩放、静音；地址/缩放/静音/阅读模式写入布局 |
| 工具栏 | 纯图标、无状态：hover、按下、焦点和打开状态都不改变底色、描边和文字颜色，点击不会留下常亮高亮；历史前进/后退不可用时仍按宿主规则淡化。「更多」是开关，按一次打开、再按一次关闭 |
| 右键 | 不注册任何右键菜单：网页、资料库条目和思源原生链接菜单都保持宿主默认行为。复制、保存、打开方式与缩放改由工具栏和页面选项面板提供 |
| 快捷键 | 网页焦点下地址栏、查找、缩放与宿主快捷键转发；编辑剪贴板快捷键留给原生网页编辑器 |
| 保存 | 当前加载 DOM 通过 Defuddle 提取并转为可编辑 Markdown，选择笔记本/父文档，新建文档；来源、时间、资源及 MHTML 状态分别记录 |
| 失败重试 | 同一任务固定文档 ID；成功资源复用；重试前检测用户修改；取消阻止后续阶段，但已经开始的网络调用可能完成 |
| 离线 | 图片/音视频 URL/下载链接尽力转存 assets；MHTML 独立保存并以禁脚本、禁网络分区打开 |
| 广告过滤 | Ghostery 引擎；应用级规则缓存、订阅设置、手动刷新、自动更新周期；失败保留可用缓存。初次默认订阅下载依赖网络。 |
| 数据隔离 | 网页使用工作空间独立持久分区；书签历史配置为工作空间插件数据；规则订阅为应用级配置 |
| 清理 | 设置中确认清理插件分区的 Cookie/缓存/站点数据；不删除笔记资源。历史和书签另行管理。 |
| 兼容降级 | 无 webview 能力时提供系统浏览器入口；不在移动端加载桌面实现 |

## 内容捕获限制

保存当前已加载内容，不递归下载普通外链，不录制流媒体，不保证登录操作、服务器交互或懒加载未出现内容能离线复现。单资源限制 32 MiB，MHTML 限制 256 MiB；blob 资源会报告未转存。失败嵌入资源从文档中移除，保留任务错误，不让笔记自动补抓远程地址。MHTML 禁用脚本后部分动态网页可能不完整。

## 验证边界

已验证与待验证分开记录在 VALIDATION.md。2026-10-14 在日常 macOS 思源中实测公开网页导航、阅读菜单与阅读模式、默认模板路径剪藏、原生正文文档和 MHTML 打开；2026-10-25 起插件不再提供右键菜单，相关分支验收项随之取消。Windows/Linux、远程内核降级、数据库模板、下载落盘、真实登录站点、完整宿主标签菜单和跨窗口配置并发尚未完成本次实机验收，公开发布不等于所有平台全部验收完成。

## 转换引擎迁移

正文提取、选区标准化、阅读模式的 Markdown 输入及保存文档的 Markdown 输出均使用 `defuddle/full`。移除原 Readability 和本项目自建 Turndown/GFM 规则；Turndown 现在仅为 Defuddle 的间接依赖。保留思源资源转存和写入 API、MHTML 快照、DOMPurify 安全净化。MathJax v2 惰性脚本在进入引擎前转为带源码的公式节点，避免被上游相邻脚本清理误删。

使用公开的 Defuddle 包，不复制 Obsidian 桌面程序代码，也不迁移 Web Clipper 的扩展 UI、模板或第三方 API 抓取。保持思源宿主适配；Obsidian 专用 callout/嵌入语法在思源中的显示能力取决于宿主。

## 标签图标与网页宽度

网站 favicon 显示于原生标签标题前，导航时恢复默认图标，异步图标响应不会覆盖已导航页面的图标。地址栏不再重复显示 favicon。网页容器明确允许在宿主分栏内缩小；默认在加载、分栏尺寸变化和页面输入/点击/动画结束后测量网页横向内容，超出视口时缩放至可见范围。手动缩放切换为固定倍率；更多菜单的“适应网页宽度”可重新启用自动适配。缩放最低为 25%，极宽页面仍可能需要横向导航。离线禁脚本归档不执行页面测量。

## 主页数据与导航

主页 DOM 位于思源宿主；工作空间数据不会注入网站网页。专用空白 guest 标记加入 Electron 导航历史，让主页参与前进和后退。仅放行这个固定标记，内置地址不作为 guest 协议加载。

访问次数保存在去重历史记录中，导航增加次数，标题事件只更新标题；旧历史从一次访问起算，删除历史也删除对应次数。关闭记录按标签保存，可重复包含同一网址。关闭主页、离线归档、卸载插件及窗口转移不产生记录。配置版本 2 迁移旧默认空白主页，并保留网站主页；版本 2 中显式设置的空白主页继续保留。

书签、历史也在宿主渲染，主页对应一个固定的空白 guest 标记；内置主页不计入访问次数、浏览历史或最近关闭。仅识别已知内部地址，不加载任意内部协议路径，也不向搜索建议提供商发送内部地址。删除单个条目只影响对应列表；设置中的浏览数据清理沿用原有范围。
